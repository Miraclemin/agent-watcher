# Agent Watcher Initial Release

This release includes:

- iPhone app bundle: `Agent-Watcher-iPhone.app.zip`
- iPad app bundle: `Agent-Watcher-iPad.app.zip`
- watchOS app bundle: `Agent-Watcher-watchOS.app.zip`

Important:

- These are development build artifacts.
- Real-device installation still requires Apple signing trust and Developer Mode.
- The recommended setup path remains building from source in Xcode using the instructions in `README.md` and `README.zh-CN.md`.

Highlights:

- Apple Watch approval handling
- Apple Watch voice input
- iPhone and iPad companion apps
- LAN, Direct, and Cloudflare deployment modes
- Persistent reusable pairing code

Documentation:

- English: `README.md`
- Chinese: `README.zh-CN.md`
